Help Admin guide

Update your website content

Use this guide to find the right admin section, make an edit, and publish it. Content you save is stored in Supabase and used by the public website.

  1. Choose a section. Use the navigation tabs. On a phone, open the menu with the button at the top.
  2. Edit the fields. Each section controls the content listed below. Check image links, email addresses, and prices before saving.
  3. Save and wait. Use the Save button in that section and wait for a successful status message. Home has its save controls at the end of its editor; some sections also have add or upload controls.
  4. Review the public page. Open that page and refresh it to confirm the change looks right on desktop and mobile.

Restore defaults puts default values back into the current form. On Home, Admission, and other editable sections, save afterward if you want those defaults published. It can replace edits that have not been saved yet.

Home

Edits the home hero, four German course cards, About section, Mission & Vision, German Journey, and Why Choose Us cards.

Use Save all Home sections at the end of the Home editor to publish the Home fields together. The course cards here are separate from the German Language page cards.

German Language

Edits the four A1, A2, B1, and B2 course cards on the German Language overview page, including image, title, duration, fee, description, and destination link.

Duration, fee, and description also update the matching A1–B2 course detail page. Choose an image link or upload an image, then save. Home page course cards are managed separately under Home.

Class Schedule

Edits the Saturday to Thursday and Weekend batch headings and rows. Each row has a session, time, and days.

Use Add weekday row or Add weekend row to add a row. Remove a row with its remove control, then save the schedule.

Admission

Edits the choices in the public registration form and the phone, availability, office days, time, and email in the “Any questions?” section.

Put one dropdown choice on each line. Save the options and contact details; the top action saves both groups.

Exam

Edits the A1, A2, B1, and B2 exam fee card headings and prices, plus the notice below the cards.

Review each level and price carefully before saving.

About Us

Edits the About Us page heading, year figures, paragraphs, and three photos. This section also contains the site-wide footer editor.

Footer changes appear across the website. Use an image link or upload a new image, then save the matching section.

Blog

Add or edit shared posts shown on Home, About Us, German Language, and Blog pages. Provide an image, attach a PDF for a new post, and enter the description visitors click to download it.

Submit the form to publish. Use the published-post controls to edit or remove a post.

Terms and Privacy

Update the text, contact details, and supported values on their public pages. Keep the provided replacement markers exactly as written, such as {minimum_age}, {refund_days}, and {jurisdiction}.

Submit the form to save changes.

Contact Us

Edits the Contact Us page map, WhatsApp number, phone, email, address, Facebook, Messenger, and YouTube links.

The WhatsApp and Messenger links also control the floating contact buttons shown across the public pages. For the map, use the Google Maps embed URL.

Gallery

Choose a category or create one, then add an image URL or upload an image and enter an optional description. Add the image, then save the gallery.

Use the controls on a listed image to remove it. Empty categories are not shown on the public Gallery page.

Messages

Shows messages submitted through the Contact Us form. Select Refresh to load the latest messages. Use a message’s remove control only when you no longer need that record.

Registered

Shows public admission form submissions. Search by the unique registration ID, or choose Show all. Use Refresh to load recent submissions.

Good editing habits

  • Make one group of related edits at a time and wait for the saved confirmation before leaving the section.
  • For links, use the complete web address beginning with https://. For site images, keep the correct file name and capitalization.
  • Preview the public page after publishing. Check that uploaded images load and contact links open the intended account.
  • Keep the admin password private. Do not put passwords, private keys, or sensitive personal information into public page text.

If a page section or field is not listed in its admin editor, that content is currently fixed in the page files rather than editable from this panel.
